Projects

1. Self-hosted identity provider (OAuth2/OIDC + MFA)

Documentation Demo

A real authorization server implementing OAuth2 and OIDC protocols with multi-factor authentication.

Stack: Go, Postgres for users/tokens, Redis for session/refresh-token state.

Key Features: Argon2id password hashing, refresh token rotation with reuse detection, short-lived JWTs, TOTP-based MFA, rate limiting on auth endpoints, structured audit logs.

2. Encrypted secrets management service (mini Vault)

Demo Documentation

An API-drive store: put/get secrets, encrypted at rest, versioned, access controlled per token.

Stack: Go, SQLite, envelope encryption (data key wrapped by a master key)

Key Features: Envelope encryption, per-secret access policies, sort-lived leased tokens, full audit trail on every read/write, rotation support.
